# SecureBoard

## Hi, I'm Asaad FETHALLAH!

SecureBoard is a hands-on DevSecOps learning project built around a FastAPI application.

The project will progressively implement:

- Automated testing
- Docker
- CI/CD
- SAST
- Secret scanning
- Dependency scanning
- Container security
- Infrastructure as Code
- Kubernetes
- DAST
- Security gates
- Supply-chain security

## Current Stack

- Python
- FastAPI
- Uvicorn
- Pytest
